# Каталог ловушек

Каждая из этих ошибок реально давала ложный положительный результат. Перед тем как
показать результат пользователю — пройти по списку.

## Ложная ровность из-за перезапуска

Считать каждый год отдельным прогоном бэктеста нельзя: у каждого запуска свой разгон
индикаторов и свои даты сделок, и получается искусственно ровная картина.

*Реальный случай:* «прибыль в каждом году» превратилось в «2023 год минус 21.5%», когда
годы посчитали внутри одного непрерывного прогона.

## Подаренный себе стоп

Ограничение убытка по позиции («не больше X% на сделку») в бэктесте исполняется идеально,
а в жизни — как повезёт. Чем жёстче ограничение, тем красивее результат.

*Реальный случай:* стоп 30% → Sharpe 2.54, стоп 50% → 1.86, без ограничения → 1.12,
а просадка выросла с 21% до 50%. Показывать надо вариант БЕЗ ограничения.

## Эквити уходит в минус

Если убыток по позиции ничем не ограничен (например шорт монеты, выросшей в 5 раз),
капитал в расчёте может стать отрицательным, и дальше формулы печатают бессмыслицу
вроде «−176% за год». Разорение обрабатывать явно: капитал не может быть ниже нуля.

## Окно удачи

Короткий период почти всегда льстит. Прежде чем радоваться — удлинить историю.

*Реальный случай:* прибыльность 3.31 на 2.5 годах превратилась в 1.84 на 4.25 годах,
и с реальными комиссиями стратегия стала убыточной.

## Отбор лучшего из многих

Выбрать лучший инструмент из пяти и лучшую настройку из шестидесяти — это подгонка,
даже если каждый шаг казался разумным. Всегда называть, из скольких вариантов выбрано.

## Линейный пересчёт издержек

Нельзя взять готовые сделки и «добавить обратно» разницу в комиссии. При другой комиссии
меняются цена входа, размер стопа, соотношение риск/прибыль и состав сделок.
Каждый уровень издержек — отдельный полный прогон.

## Ошибка выжившего

Брать сегодняшний список инструментов = выбросить всех, кто обанкротился. Для крипты
обязательно добавлять делистнутые пары (см. `data-sources.md`).

## Показатель биржи вместо реального результата

Цифра «прибыль» в рейтинге биржи может включать рост спотовых активов, а не торговлю.

*Реальный случай:* в топ по эффективности попали держатели токена; их средний выигрыш
составлял 0.44 среднего проигрыша при винрейте 44.8% — то есть на сделках они теряли.
Считать прибыль только из истории ордеров.

## Перекрывающиеся окна при проверке устойчивости

«Результат за месяц» включает в себя ту неделю, которую пытаемся предсказать. Такая
проверка завышена по построению. Использовать только непересекающиеся окна.

## Сложность как ухудшение

Каждое «логичное улучшение» добавляет степень свободы и шум. Проверять улучшения
по одному на разделённой выборке.

*Реальный случай:* шесть обоснованных улучшений по отдельности не подтвердились,
а все вместе уронили результат с 1.17 до 0.27. Помогло единственное — не добавить,
а **убрать** самые волатильные инструменты.

## Маленькая выборка

30–50 сделок — это ни о чём. При таком объёме прибыльность выше 3 получается случайно
без всякого преимущества. Нужно 200+, лучше 500+.

## Идеализированное исполнение

Вход по цене закрытия бара, мгновенное исполнение по нужному уровню, отсутствие
проскальзывания, отсутствие свопа при удержании часами. Всё это льстит. Особенно
критично при тесном стопе: там проскальзывание в один пункт — это проценты риска.
