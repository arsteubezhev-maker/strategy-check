# Батарея проверок

Каждая ловит свой вид самообмана. Пропуск любой из них — типичная причина того,
что бэктест показал прибыль, а живая торговля дала убыток.

## 1. Есть ли сигнал вообще (нулевые издержки)

Прогнать с комиссией = 0. Это отделяет «правила ничего не предсказывают» от
«предсказывают, но мало».

Если прибыльность при нулевых издержках ниже 1 — **остановиться здесь**. Настраивать
нечего: сигнала нет. Дальнейшие тесты бессмысленны.

## 2. Реальные издержки и порог безубыточности

Прогнать при нескольких уровнях комиссии (например 0 / 0.02% / 0.04% / 0.08% / 0.1%)
и найти, при какой результат = ноль. Сравнить с доступным тарифом.

Отдельно посчитать **издержку как долю риска сделки**:
```
доля = комиссия_на_круг × цена_входа / размер_стопа
```
Больше 15% — стратегия структурно обречена. У систем с очень тесным стопом
(«за тень свечи») выходит 25–30%, и это убивает даже хороший сигнал.

⚠️ Пересчитывать издержки задним числом линейно НЕЛЬЗЯ — при другой комиссии меняется
цена входа, размер стопа, соотношение риск/прибыль и состав сделок. Каждый уровень
издержек — отдельный полный прогон.

## 3. Перестановочная проверка (главная)

Заменить сигнал случайным (сохранив всю остальную механику: размеры, стопы, цели,
издержки) и прогнать 15–20 раз с разными зёрнами случайности. Сравнить распределение
случайных результатов с реальным.

Это единственный способ отличить «стратегия работает» от «повезло на этих данных».
Если реальный результат попадает внутрь разброса случайных — сигнала нет, какой бы
красивой ни была кривая доходности.

Важно: сравнивать на **одинаковых условиях**. Если реальный прогон считался без стопа,
случайный тоже должен быть без стопа.

## 4. Разделение выборки

Поделить период пополам: на первой половине смотрим и настраиваем, на второй только
проверяем. Улучшением считается только то, что работает на обеих половинах.

Признак подгонки: знак результата меняется между половинами. Одно из самых частых
разоблачений — идея даёт +1.09 на второй половине и −0.25 на первой.

## 5. Устойчивость по параметрам

Прогнать соседние значения каждого параметра. У настоящего эффекта результат меняется
плавно и есть широкая область рабочих настроек. У подгонки соседние значения дают
противоположный ответ.

Хороший признак — монотонность: если ужесточение фильтра улучшает результат на всех
порогах подряд, это эффект, а не удачное число.

## 6. Перенос на другие инструменты

Прогнать на 5+ инструментах. Результат на одном инструменте — это одна выборка,
а не подтверждение. Сообщать долю инструментов, где стратегия прибыльна.

Осторожно с отбором: выбрать лучший инструмент из десяти — это и есть подгонка.
Если пришлось выбирать, сказать об этом прямо и проверить, широкая ли вокруг него
область (соседние инструменты и настройки тоже должны быть неплохими).

## 7. Доходность по годам — из ОДНОГО непрерывного прогона

Сгруппировать сделки одного прогона по годам. Не запускать бэктест отдельно на каждый
год: у каждого запуска свой разгон и свои даты входа, и это создаёт ложную ровность.

## 7a. Распределение причин выхода

Посчитать, сколько сделок закрылось по стопу, по цели и по таймауту. Если таймаут
доминирует — тестируется не то, что описано в правилах (см. `traps.md`).

## 7b. Монотонность градиента параметров

Если улучшение идёт монотонно по всему ряду (шире стоп → лучше, дальше цель → лучше,
дольше держать → лучше), это признак настоящего эффекта: у подгонки хорошие значения
разбросаны случайно. В таком случае «лучшая» настройка — конец градиента, а не
счастливая точка, и риск отбора ниже. Но сказать об этом честно всё равно нужно.

## 7c. Разложение результата на составляющие

Если прибыль складывается из нескольких источников (финансирование + базис, сигнал +
плечо, цена + дивиденд), посчитать вклад каждого и корреляцию итога с каждым.
Без этого легко объяснить результат не той причиной и «починить» не то место.

## 8. Ёмкость и ликвидность

Ограничить вселенную инструментами с реальным оборотом и посмотреть, выживает ли
эффект. Частый исход: работает только там, где нельзя исполнить объём.

Для крипты — фильтр по среднему дневному обороту ($20M / $50M / $100M).

## 9. Расширение выборки

Если сделок меньше ~200, результату верить нельзя. Увеличивать период и число
инструментов, пока выборка не станет осмысленной, и **сравнивать с первым прогоном**:
если при удлинении истории показатели заметно падают — первый результат был окном
удачи.

## Особые случаи

**Спот-стратегии (сетка, усреднение).** Правильный эталон — не ноль, а «купить и
держать». Многие сеточные боты прибыльны и при этом хуже простой покупки. Считать
стоимость портфеля как деньги + активы по рынку, а не только реализованную прибыль.
Проверять на скользящих годовых окнах: результат сильно зависит от точки входа.
