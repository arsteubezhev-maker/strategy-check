# Рабочие источники данных

Проверено 2026-08. Всё бесплатно и без ключей API.

## Крипта — Binance, публичные дампы (основной источник)

Самый надёжный. Помесячные архивы, любой инструмент, любой таймфрейм.

```
https://data.binance.vision/data/futures/um/monthly/klines/{SYM}/{TF}/{SYM}-{TF}-{YYYY-MM}.zip
```
`TF` = `1m` `5m` `15m` `1h` `4h` `1d`. Внутри CSV без заголовка (в свежих файлах —
с заголовком, проверять первую строку). Колонки:
`open_time, open, high, low, close, volume, close_time, quote_volume, count, taker_buy_volume, taker_buy_quote_volume, ignore`.

⚠️ `open_time` бывает в миллисекундах и в микросекундах — определять по величине
(`> 1e15` → микросекунды).

Готовый загрузчик: `scripts/fetch_binance.py`.

### Сделки с флагом агрессора (для order-flow)
```
.../monthly/aggTrades/{SYM}/{SYM}-aggTrades-{YYYY-MM}.zip
.../daily/aggTrades/{SYM}/{SYM}-aggTrades-{YYYY-MM-DD}.zip
```
Поле `is_buyer_maker`: `true` = агрессивная продажа, `false` = агрессивная покупка.
Из этого считаются дельта, CVD, крупные сделки. День по BTC ≈ 13 МБ архив / 73 МБ CSV.

### Список ВСЕХ инструментов, включая делистнутые
Критично против ошибки выжившего: если брать только сегодняшние монеты, умершие
проекты исчезнут из истории и результат будет завышен.
```
https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=data/futures/um/monthly/klines/
```
Возвращает XML со всеми префиксами (~830 пар USDT). Живые торгуемые:
`https://fapi.binance.com/fapi/v1/exchangeInfo`. Разница = делистнутые.

### Быстрая загрузка живых инструментов
`https://fapi.binance.com/fapi/v1/klines?symbol=BTCUSDT&interval=1d&limit=1500`
— один запрос на инструмент, до 1500 баров. Только для торгуемых сейчас.

### Спот
`https://api.binance.com/api/v3/klines?symbol=BTCUSDT&interval=1h&startTime=…&limit=1000`
— с постраничной подкачкой. Комиссия спота 0.1% за сделку (вдвое дороже фьючерсов),
это надо закладывать.

## Ончейн-биржа — Hyperliquid (для изучения живых трейдеров)

Здесь история сделок каждого адреса публична и её нельзя подделать или скрыть.

- Рейтинг всех адресов (~41 тыс., 34 МБ):
  `https://stats-data.hyperliquid.xyz/Mainnet/leaderboard`
- История ордеров: `POST https://api.hyperliquid.xyz/info`
  `{"type":"userFills","user":"0x…"}` — до 2000 последних сделок.
  Полезные поля: `crossed` (false = мейкер), `closedPnl`, `dir` (Open/Close Long/Short),
  `fee`, `coin` (начинается с `@` = спот, отфильтровать для фьючерсов).
- Кривая капитала: `{"type":"portfolio","user":"0x…"}`

⚠️ Показатель PnL в рейтинге включает рост спотовых активов. Считать торговую прибыль
только как сумму `closedPnl` по фьючерсам минус комиссии.

## Форекс

- **HISTDATA — автоматическая загрузка сломана** (с 2026-08 страница пары/года отдаёт
  общий лендинг без формы). Уже скачанные архивы лежат в `~/Downloads/HISTDATA_COM_MT_*.zip`;
  внутри `DAT_MT_{PAIR}_M1_{YYYY}.csv`, формат `YYYY.MM.DD,HH:MM,O,H,L,C,V`.
  Файлы `.txt` рядом — это отчёты о выгрузке, НЕ данные.
- Альтернативы: тиковый фид Dukascopy (`.bi5`), либо загрузка через реальный браузер.
- Для проверки «работает ли идея на разных инструментах» проще брать крипту: там много
  инструментов на одинаково надёжных данных.

## Что закладывать в издержки

| Рынок | Реалистично на круг |
|---|---|
| Binance фьючерсы, тейкер | 0.08% (0.04% × 2) |
| Binance фьючерсы, мейкер | 0.02% |
| Binance спот | 0.2% (0.1% × 2) |
| Форекс мажоры | 1–2 пункта (спред + своп при удержании часами) |

Всегда прогонять несколько уровней издержек, а не один: важен не результат при
конкретном тарифе, а **порог, при котором результат обнуляется**.
