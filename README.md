# strategy-check

Навык для Claude Code, который **честно проверяет торговые стратегии** на реальных
данных — вместо того чтобы верить PDF-кам, ютуб-гуру и красивым кривым доходности.

Приносишь идею: «вот стратегия из ебука», «этот трейдер делает 200% в год»,
«а что если откупать падения» — и получаешь ответ с цифрами за пару часов вместо
месяцев веры.

Почти всегда ответ отрицательный. **Это и есть ценность:** отрицательный ответ
экономит деньги, которые иначе ушли бы в рынок и на курсы.

## Зачем это

Главная проблема бэктеста не в том, что стратегия не работает. Проблема в том, что
**бэктест легко показывает прибыль, которой нет**. Навык кодирует набор проверок,
каждая из которых ловит свой вид самообмана, и каталог ловушек — все они реально
давали ложный положительный результат.

Примеры из каталога:

- Считать каждый год отдельным прогоном — создаёт ложную ровность. «Прибыль в каждом
  году» превратилось в «−21.5% в 2023-м», когда годы посчитали внутри одного прогона.
- Ограничение убытка по позиции — подарок себе: стоп 30% давал Sharpe 2.54, без
  ограничения — 1.12, а просадка выросла с 21% до 50%.
- Короткое окно льстит: прибыльность 3.31 на 2.5 годах стала 1.84 на 4.25 годах.
- Брать сегодняшний список инструментов = выбросить всех, кто обанкротился.
- Шесть «логичных улучшений» вместе уронили результат с 1.17 до 0.27.

## Ключевые проверки

| Проверка | Что ловит |
|---|---|
| Прогон при нулевых издержках | есть ли сигнал вообще |
| Порог безубыточности по комиссии | сигнал есть, но меньше издержек |
| **Перестановочный тест** | «работает» против «повезло» |
| Разделение выборки | подгонку под период |
| Устойчивость по параметрам | подгонку под число |
| Перенос на 5+ инструментов | подгонку под инструмент |
| Ёмкость и ликвидность | эффект там, где нельзя исполнить объём |

Отдельная метрика, которая закрывает большинство скальпинг-идей:
**издержка как доля риска сделки** = `комиссия × цена / размер стопа`.
Больше 15% — стратегия обречена независимо от качества сигнала. У систем со стопом
«за тень свечи» выходит 25–30%.

## Результаты, на которых навык построен

Восемь проверенных стратегий, один механизм провала: **частая торговля с маленьким
стопом проигрывает издержкам.**

| Идея | Итог |
|---|---|
| Индикаторный скальпинг (VWAP/SuperTrend/RSI) | 1.04 без издержек → 0.39 с ними |
| Mean-reversion, momentum | 0.96 и 0.98 **без издержек** — сигнала нет |
| ICT / Smart Money | убыточно во всех вариантах |
| Donchian-брейкаут на форексе | ноль при реалистичном учёте свопа |
| Order-flow из aggTrades (CVD, дельта) | корреляция с будущей доходностью ≈ 0 |
| «Торговать наоборот» | все 10 вариантов сливают счёт |
| CCT Rectangle (519 сделок, 8 монет) | 0.49 с комиссией, 0.96 при идеальной |
| Кросс-секционный моментум | **прошёл** перестановочный тест, но ёмкость мала |
| Спот-сетка | прибыльна, но проигрывает простой покупке |

Проверка на живых трейдерах (ончейн-биржа, все 41 324 адреса): **прошлый результат
не предсказывает будущий** — верхний дециль даёт 31.6% прибыльных в следующем месяце
против 42.3% в среднем по всем. Единственный признак, который реально отличает
прибыльных от убыточных, — **не доливаться к убыточным позициям** (66% прибыльных
у тех, кто почти не доливает, против 30% у тех, кто доливает часто).

Никакого «секрета входа» не обнаружено.

## Установка

Скопировать папку `skill` в директорию навыков Claude Code:

```bash
git clone https://github.com/<user>/strategy-check.git
cp -r strategy-check/skill ~/.claude/skills/strategy-check
```

Дальше просто спросить Claude Code: «проверь вот эту стратегию» — навык подхватится сам.

## Правка под себя

Всё написано обычным текстом по-русски и рассчитано на правку без программирования:

- новую ловушку — дописать в `references/traps.md`;
- новый источник данных — в `references/data-sources.md`;
- **после каждой проверки дописывать вывод в `references/prior-results.md`** — это
  главное, что делает навык умнее со временем.

## Оговорка

Навык не даёт торговых рекомендаций и не запускает сделки. Он только считает и
показывает цифры. Решения о деньгах — за вами.
